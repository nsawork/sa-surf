# SA.SURF

> Portfólio audiovisual desenvolvido para apresentar projetos de fotografia e produção de vídeos com drone, surf, esporte, lifestyle e conteúdo digital.

🌐 **Live:** https://sa-surf.vercel.app/

---

## Sobre o projeto

O **SA.SURF** é um portfólio digital desenvolvido para apresentar trabalhos de produção audiovisual e captação aérea.

O projeto combina uma interface minimalista com animações, vídeos, fotografias e experiências interativas para apresentar diferentes trabalhos e projetos de forma visual.

Além da produção audiovisual, o projeto também demonstra minha experiência com desenvolvimento web, integração de mídias, responsividade e deploy em produção.

---

## ✨ Funcionalidades

* Portfólio de projetos audiovisuais
* Apresentação de fotografias e vídeos
* Vídeos com reprodução manual
* Experiência responsiva para desktop, tablet e mobile
* Animações e transições de página
* Navegação entre projetos
* Visualização de imagens em alta resolução
* Experiência interativa com panorama 360°
* Cursor personalizado inspirado em prancha de surf
* Integração com Instagram e WhatsApp
* Otimização de carregamento de mídias
* Deploy em produção com Vercel
* Git LFS para gerenciamento de arquivos de mídia

##  Objetivo

O projeto foi desenvolvido com dois objetivos principais:

**Audiovisual:** apresentar trabalhos de fotografia, vídeo e captação aérea.

**Desenvolvimento:** aplicar conhecimentos de desenvolvimento web, arquitetura de componentes, responsividade, animações, gerenciamento de mídia e publicação de aplicações em produção.
